ONLINE VOTING SYSTEM - SDC REVIEW 1
===================================

TECHNOLOGIES
HTML, CSS, JavaScript and Local Storage.

ACCESS MODES
1. USER / VOTER
   - Sign up and login
   - Open voter dashboard
   - View participating parties
   - Click a party to see leaders, roles and selected historical election results
   - Cast one demonstration vote
   - View results

2. ADMIN
   - Open Login and select "Admin Login"
   - Demo email: admin@election.gov.in
   - Demo password: admin123
   - View total votes, registered demo voters, voting status and leading party
   - Open/close voting
   - Reset demonstration election data
   - View live party vote counts

IMPORTANT
This is an academic prototype. Role authentication and election data are stored in Local Storage and are NOT secure enough for a real election system. The admin credentials are intentionally included for classroom demonstration.

RUN
Extract the ZIP and open index.html in a browser.
